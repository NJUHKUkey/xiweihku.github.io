# Xi Wei Academic Website

This is a Vite + React + TypeScript academic homepage project.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload this project.
3. Use GitHub Actions or a static hosting service like Vercel/Netlify.

For the easiest path with GitHub Pages, you can either:
- deploy the `dist` folder manually after `npm run build`, or
- add a GitHub Actions workflow for Vite deployment.
