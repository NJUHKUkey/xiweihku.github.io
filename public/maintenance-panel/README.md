# Academic Website Maintenance Panel

This panel edits the structured database for the academic website.

Published panel URL:

```text
https://xiweihku.github.io/maintenance-panel/
```

Primary data file:

```text
public/data/content.json
```

The current public website still renders from the existing React source. This panel and data file are added as a maintenance foundation only. A later step can connect the React homepage to `content.json` so site updates only require editing the data file.
